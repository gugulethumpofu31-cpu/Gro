# GRO · Living Garden

GRO is a responsive, single-file browser prototype for a personal life-management garden. It organises eight areas of life into distinct botanical plots, with Banga as a companion who offers contextual observations and reflective prompts.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser such as Chrome, Edge, Firefox or Safari.
3. Your tasks, plot information and journal entries are saved in that browser's local storage.

No build step or package installation is required for this prototype.

## The eight plots

- Career: The Canopy of Ambition
- Education: The Library Grove
- Home: The Hearth Garden
- Wellbeing: The Resting Spring
- Creativity: The Wildflower Atelier
- Finance: The Orchard of Resources
- Relationships: The Woven Courtyard
- Experiences: The Wayfinder Meadow

Each plot has its own visual identity and dashboard.

## Current features

- Eight individual life-area gardens with distinct palettes, settings and descriptions.
- Plot-specific goals, target dates and progress tracking.
- Tasks, including optional percentage, subtask and milestone-based progress tracking.
- Plot-specific habits with daily check-ins and flexible cadence.
- Milestones with target dates and completion history.
- Upcoming deadlines drawn from open tasks, goals and milestones.
- Plot journal notes and historical achievements.
- Contextual Banga observations and reflective questions in every plot.
- Garden-style progress indicators and the Growth Observatory.
- Banga's daily rhythm, configured for Africa/Harare: wake at 06:00, bedtime at 22:30, and sleep-and-dream behaviour at night.
- Browser-local data persistence.

## Important limitations

This is an early local prototype. Data is stored in the browser's local storage and does not yet synchronise across devices. Authentication, a cloud database, live AI responses, personalised astrological calculations, African wisdom content feeds and current-affairs integrations are planned for later development. Banga's current observations are prototype content, not live AI-generated advice.

## Privacy and data

Your GRO data stays in the browser profile where you use the app. Clearing that browser's site data may remove it. Use the app's available export/backup function where applicable and keep a separate copy of important information.

## Project direction

GRO is being developed iteratively. The next stages include a hosted deployment, secure cloud synchronisation, richer Banga experiences and integrations for relevant daily intelligence.
